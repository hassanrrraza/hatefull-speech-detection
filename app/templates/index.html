Roman Urdu Tip

Roman Urdu lacks standard spelling rules (e.g. bohat vs bht). The model uses generalized n-gram patterns to maximize detection accuracy.

How Roman Urdu AI Detection Works

1

Text Cleaning & Case Normalization

Input text is converted to lowercase, non-alphanumeric punctuation marks are stripped, and whitespace is normalized.

2

Roman Urdu Stopword Filtering

Common Roman Urdu grammatical words like aur, hai, ke, ka, ki, ko, the, main, tum, wo are removed to highlight meaningful semantic words.

3

TF-IDF Vectorization

The cleaned tokens are projected into a high-dimensional TF-IDF feature space matching the trained dataset vocabulary.

4

Random Forest Ensemble Classification

Multiple decision trees vote on whether the text is safe or hateful, calculating exact probabilistic confidence scores.
